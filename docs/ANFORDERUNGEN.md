# Anforderungen

## Ziel

Ein Terrassenkonfigurator, der in modul-garten.de eingebettet wird. Kunden konfigurieren ihre Terrasse, sehen einen Richtpreis und können direkt **vorbestellen**. Später folgen weitere Konfiguratoren (Pergola, Modulhaus) auf derselben Basis.

Der Ablauf im Detail steht in `PROZESS.md`.

## Bekannte Fakten (Stand 2026-11-06)

| Thema | Antwort |
|---|---|
| Entwicklung & Wartung | Chris + Claude, kein externer Entwickler |
| Website | WordPress + WooCommerce. Ein **Relaunch** ist geplant: neues Template und angepasste Plugins, abgestimmt auf den Konfigurator |
| Sortiment | **3 Varianten**. Platten mind. **2,5 cm** dick. Abrechnung **pro m², ca. 250 €/m²** |
| Preispflege | Wünschenswert, vorerst minimalistisch |
| Darstellung | 3D, gern kombiniert mit 2D, wenn das die Bedienung erleichtert |
| Zielgruppe | Privat- **und** Gewerbekunden |
| Einzugsgebiet | ca. 50 km |
| Zeitplan | Kein fester Termin, iterativ losbauen |
| Geschäftsmodell | Vorbestellungen, Ziel **20–30 durchterminierte Vorbestellungen**, unnötigen Aufwand vermeiden |
